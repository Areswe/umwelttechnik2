# Umwelttechnik Lern-App v2

GitHub-Pages-taugliche Lernplattform für Umwelttechnik.

## Enthalten
- 102 klausurrelevante Fragen
- Sofort sichtbarer Fortschritt je Kapitel
- Spaced-Repetition-Logik
- Prüfungsmodus mit 30 Fragen
- Schwache-Fragen-Liste
- Dark Mode
- Export/Import des Lernstands

## GitHub Pages
Diese Dateien in dein Repository hochladen:

- `index.html`
- `style.css`
- `app.js`
- `questions.js`

Dann unter **Settings → Pages** auf **Deploy from branch / main / root** stellen.
